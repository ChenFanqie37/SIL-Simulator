# 💕 韩娱嫂嫂模拟器

> 你背着全世界和他恋爱。

一款韩娱地下恋爱生存模拟器。通过手机模拟器界面，体验与韩国偶像的秘密恋爱——在粉丝的怀疑、公司的管控、狗仔的追拍中维持这段地下恋情。每个选择都会影响后续舆论、男友态度、公司反应和最终结局。

## ✨ 核心玩法循环

```
KakaoTalk聊天互动
  → 触发约会/吵架/冷战/撒糖/暴露风险
  → Instagram/Weverse/Naver/Dispatch 产生外界反应
  → 公司发来警告或管控
  → 玩家做选择：澄清/装死/删动态/逼他公开/哄他/冷处理/控评/反击
  → 行动留下手机痕迹 → App之间传播 → 延迟后果爆发
  → 数值变化 + 男友情绪变化 + 男友记忆更新
  → 推进到下一回合或下一章节
```

**每个 App 不是孤立的，所有 App 都像真实手机一样互相影响。每个行动都会在手机世界留下真实痕迹。**

## 🆕 v2.0 新增系统

### ⏳ 延迟后果系统
今天一个小动作，当下看起来没事，几天后突然爆雷。每个关键选择可能触发延迟后果：
- 2回合后：Weverse出现分析帖
- 3回合后：Naver出现标题党新闻
- 4回合后：公司通知警告
- 5回合后：男友质问"你是不是故意的？"

### 🔍 证据碎片系统
危机不是系统直接告诉你"你暴露了"，而是通过各种碎片让你自己意识到危险：
- Instagram照片背景的倒影
- 男友Story里的玻璃反光
- 相册里约会的照片
- Weverse粉丝截图
- KakaoTalk聊天记录
- 行程表时间重合

每个证据有风险等级，粉丝怀疑越高，证据被发现概率越高：
- 粉丝怀疑 < 30：大多数证据没人注意
- 粉丝怀疑 30-60：粉丝开始截图分析
- 粉丝怀疑 > 60：粉丝把多个证据串成时间线
- 粉丝怀疑 > 80：进入"扒皮阶段"

### 📋 粉丝扒皮时间线
当粉丝怀疑超过50且发现多个证据后，Weverse自动生成扒皮时间线帖：
- "我把最近的时间线整理了一下，真的只是巧合吗？"
- "不是我想多，但这些证据串起来太巧了"
- "越看越不对劲...时间线全对上了"

### 🧠 男友记忆系统
LLM不再每次像重置一样。男友会记住：
- 你是否逼过他公开（多次要求会触发"또 그 얘기야?"）
- 你是否删过动态
- 你是否在危机时保护过他
- 你是否冷战过
- 你是否说过分手
- 上次吵架的原因
- 未解决的矛盾

### 💬 KakaoTalk真实聊天机制
- **已读不回**：回避型、压力高时概率更高，玩家可选择追问/装没事/冷处理
- **正在输入中...**：先显示typing状态，有时typing很久但最后没发出来
- **撤回消息**：男友可能发一句危险的话然后撤回，玩家可选择追问/截图保存
- **语音消息**：显示"语音消息 0:07"，点击显示文字转写
- **通话记录**：打电话后KakaoTalk出现通话记录（已接/未接/拒接/旁人在场）
- **已读/未读状态**：玩家消息显示已读/未读

### 🚨 危机处理面板
危机等级Level 1-5，当危机升级时弹出策略选择面板：
1. 🤫 装死 — 短期降低曝光，但粉丝继续挖
2. 🗑️ 删除证据 — 降低风险，但"删了就是心虚"
3. 💬 让他解释 — 取决于男友人设
4. 🔥 发烟雾弹 — 转移注意，但可能引发更大误会
5. 🛡️ 控评 — 短期降低热度，但隐私下降
6. 💪 正面硬刚 — 精神上升，但曝光和公司警觉大幅上升
7. 🏢 求助经纪人 — 公司警觉上升，但可能压下媒体
8. 📁 保存证据 — 影响黑化/反制公司结局

## 🔑 API 配置

游戏使用 Google Gemini API 驱动 LLM 功能（聊天、翻译、内容生成）。

### 首次启动
1. 打开游戏后，会自动弹出 API 配置界面
2. 至少填写 1 个 API Key 即可开始游戏
3. 最多支持 8 个 Key，每个 Key 负责不同功能，避免限流

### Key 分配方案
| Key | 负责功能 | 说明 |
|-----|----------|------|
| Key 1 | 💬 聊天 | KakaoTalk聊天回复 |
| Key 2 | 🟢 Weverse | 粉丝社区帖子 |
| Key 3 | 📰 Naver | 娱乐新闻 |
| Key 4 | 🏢 公司 | 公司通知 |
| Key 5 | 📸 Dispatch | 狗仔爆料 |
| Key 6 | 📢 事件 | 随机事件+Instagram |
| Key 7 | 💕 约会 | 约会事件 |
| Key 8 | 🌐 翻译 | 韩语翻译 |

### 获取 API Key
1. 访问 [Google AI Studio](https://aistudio.google.com/)
2. 点击 "Get API Key"
3. 创建项目并获取 Key（免费）
4. 可创建多个 Key 分配给不同功能

### 修改 API Key
- 游戏主界面点击 ⚙️ 设置图标
- 或在 KakaoTalk 等App内点击设置入口

> ⚠️ 没有 API Key 也能玩！选择"离线模式"，所有功能都有本地韩文 fallback 回复。

> 🔒 你的 API Key 保存在浏览器 localStorage 中，不会上传到任何服务器。代码中不包含任何硬编码的 API Key，可以安全分享。

## 🎮 游戏玩法

1. **选择身份**：8种身份，每种有特殊能力、风险和2条专属剧情
2. **选择人设**：7种隐藏人设，决定他的真实性格和结局路线
3. **聊天互动**：在KakaoTalk与他韩文聊天，每3条消息推进1回合

5. **应对事件链**：5条连续事件链+8种身份专属事件+9种男友主动事件
6. **主动行动**：点击"⚡ 行动"执行操作，每个行动留下手机痕迹
7. **应对危机**：危机处理面板，8种策略各有代价
8. **查看动态**：Weverse/Naver/Instagram了解外界声音
9. **收集证据**：证据碎片系统，粉丝可能发现并整理时间线
10. **记录回忆**：约会记录和备忘录记录你们的点滴
11. **最终审判**：回顾关键选择，走向19个结局之一
